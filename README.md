# ferntastic site

a really bad personal site!

this project was made with [astro](https://astro.build) and [deno](https://deno.com)

## running it

prerequisites:
- deno installed

1. git clone this repository
2. `cd` into it (`cd site` for example)
3. `deno install` to install all packages
4. `deno dev` to run the dev preview on port `4321`
5. to build, run `deno build` and then `deno preview`!
6. enjoy!

## other astro commands

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `deno install`             | installs dependencies                            |
| `deno dev`             | start dev server at `localhost:4321`      |
| `deno build`           | build production site to `./dist/`          |
| `deno preview`         | preview build locally, before deploying     |
| `deno astro ...`       | run CLI commands like `astro add`, `astro check` |
| `deno astro -- --help` | get help using the Astro CLI                     |
