# site

## astro commands

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `deno install`             | installs dependencies                            |
| `deno dev`             | start dev server at `localhost:4321`      |
| `deno build`           | build production site to `./dist/`          |
| `deno preview`         | preview build locally, before deploying     |
| `deno astro ...`       | run CLI commands like `astro add`, `astro check` |
| `deno astro -- --help` | get help using the Astro CLI                     |
